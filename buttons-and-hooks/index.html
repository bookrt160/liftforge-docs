    Help, Phone and Emergency Call buttons¶

    The car operating panel has Help, Phone and Emergency Call buttons. In 1.0 they are hooks only: pressing one is accepted and raises On Command Executed, and nothing else happens. What the button does in your project (play a voice line, open a UI, call a function, notify a server) is up to you.

    The same event is raised after every command, so you bind once and filter by command.

    Bind in Blueprints¶

    1. Get a reference to the elevator (for example from a level Blueprint or an actor that has the elevator as a variable).
    2. Drag from the elevator and choose Assign On Command Executed (in the Elevator > Events category).
    3. In the custom event, which receives Elevator, Command, Floor Id and Accepted, add a Switch on ELFElevatorCommand (or a == check).
    4. On Help, Phone or Emergency Call, run your own logic.

    Do this in Begin Play so the binding exists before anyone presses a button. For many cars, bind each one when you spawn or find it.

    Bind in C++¶

    // MyActor.h
UFUNCTION()
void HandleCommand(ALFElevator* Elevator, ELFElevatorCommand Command, FName FloorId, bool bAccepted);

// MyActor.cpp, for example in BeginPlay
Elevator->OnCommandExecuted.AddDynamic(this, &AMyActor::HandleCommand);

void AMyActor::HandleCommand(ALFElevator* Elevator, ELFElevatorCommand Command, FName FloorId, bool bAccepted)
{
    switch (Command)
    {
    case ELFElevatorCommand::EmergencyCall: /* alert the control room */ break;
    case ELFElevatorCommand::Help:          /* show help */ break;
    case ELFElevatorCommand::Phone:         /* start the intercom */ break;
    default: break;
    }
}

    Fire the buttons yourself¶

    Execute Elevator Command with EmergencyCall, Help or Phone raises the same event, so a UI button or a test can use the same path as a physical button press.

    Button names¶

    A generated button stores its command as text so that levels saved with older versions keep working. The names never change: Select, Up, Down, Destination, Open, Close, Alarm, EmergencyCall, Help, Phone, Cutaway, Exploded, Labels, Overload, Obstruction, Normal, Independent, Maintenance, FireRecall, OutOfService, DoorJam, PowerLoss, EmergencyBrake, Stuck, Reset, Resume, JogUp, JogDown.

    A button whose name is not in the list logs one warning when pressed and does nothing. If a custom button seems dead, check the Output Log for that warning. Use Set Command Type to choose a command from the enum instead of typing a name.
