    Install¶

    Requirements¶

    Item Requirement
    Engine Unreal Engine 5.6, 5.7 or 5.8. Download the plugin build that matches your engine version.
    Platform Windows 64-bit (Win64).
    C++ toolchain Only if you build the plugin yourself or your project already has C++ code. Use the toolchain your engine version asks for.
    Plugins used Enhanced Input, MetaSounds, XRBase, StateTree and GameplayStateTree (all shipped with the engine; the last two are for NPC riding). OpenXR is optional and only needed for headsets.

    The three MetaSound sources need the MetaSounds plugin, which the plugin enables for you. Epic's guide: https://dev.epicgames.com/documentation/en-us/unreal-engine/metasounds-quick-start

    Install from Fab¶

    1. Open the Epic Games Launcher, go to Fab in your library and find LiftForge.
    2. Choose Install to Engine for the engine version you use (check the wording in your launcher version). Fab provides one download per engine version.
    3. Restart the editor, open Edit > Plugins, search for LiftForge and make sure it is enabled.
    4. If you build your own project from source, regenerate the project files and compile once. Plugin binaries are built by Epic for the versions Fab lists.

    Installing LiftForge as an engine plugin has been proven on UE 5.6 only.

    Install by hand (project plugin)¶

    Copy the LiftForge folder into your project's Plugins folder (create it if needed), so you have YourProject/Plugins/LiftForge/LiftForge.uplugin. Open the project. If Unreal asks to rebuild modules, accept. A manual copy has no compiled code, so it needs Visual Studio with C++ so Unreal can build it. Without them, install from Fab.

    Show the plugin content¶

    In the Content Browser open Settings and enable Show Plugin Content. The LiftForge content is under LiftForge Content:

    Folder Contents
    Presets DA_Preset_<Key> data assets, one per preset
    VisualSets DA_VisualSet_<Key> data assets
    Blueprints BP_LF_<Key> ready-to-place elevators
    Materials Master materials (Masters) and material instances (Instances)
    Meshes Kit and HQ meshes
    Textures Surface maps, signage images and HDRI cubemaps
    Audio Sound waves, three MetaSound sources, attenuation and sound mix
    Input Enhanced Input assets used by the demo pawns
    Examples/Maps LF_Showcase_Warm and LF_Showcase_Noir, the example maps
    Examples/AI The sample NPC (BP_LF_SampleNPC)

    Project settings¶

    LiftForge needs no project settings to run. Optional settings live under Project Settings > Plugins:

    • LiftForge: the assets every car uses when a preset does not point at its own (kit meshes, kit materials, LED materials, sound attenuation, sound mix), Apply Sound Mix and the parked-car tick interval. Changes are saved to your project's Config/DefaultLiftForge.ini. The cooker packages these assets automatically, so you do not need a "Directories to always cook" entry.
    • LiftForge Demo: Apply VR Performance CVars, the VR laser material and the Input Config asset. See VR setup and Using your own character.

    Check the install¶

    Open /LiftForge/Examples/Maps/LF_Showcase_Warm and press Play. You stand in a lobby with a bank of passenger cars. Walk up to a button and press it. If something is missing, see FAQ and troubleshooting.
